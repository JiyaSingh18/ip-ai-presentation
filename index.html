IP Types Defined

Six IP categories — definition & Makad fit

IP typeDefinitionApplies to Makad?
Copyright Primary Legal right over original expressive works fixed in a medium — code, art, audio, literature (§13, Copyright Act 1957) Yes. Animations, astromech sounds, storyboard, renders, firmware, docs — all my authored works. Automatic on creation.
Patent Limited 20-year monopoly on a novel, non-obvious invention with industrial application (§2(1)(j), Patents Act 1970) Unlikely now. 3-axis head mechanism has prior art in desktop robots. Student V1 doesn't justify filing cost or novelty bar.
Trade Secret Limited Confidential business information giving competitive advantage — protected by secrecy, not registration Contradicted. Architecture and storyboard are public on GitHub. Motion tuning could be secret only if kept private pre-demo.
Trademark Future Registered mark identifying product origin and preventing consumer confusion (Trade Marks Act 1999) Not yet. "Makad" / "M4K4-D" aren't commercial products. Would matter if I productized and entered market.
Research Paper Academic Published scholarly work — creates prior art, cites existing knowledge, documents original contribution Yes — inbound. RP-01 storyboard cites Plos One 2024 nod kinematics. My docs are original; cited papers constrain patent claims.
Industry Product Comparator Commercial product whose IP portfolio, licensing, and shutdown behaviour inform strategy Yes — Anki Vector. Direct parallel: AI companion robot, cloud NLU, expressive face, company shutdown 2019.

Criterion ① · Patent, Trade Secret, Trademark applied to Makad
Other IP Types

Why patent, trade secret & trademark are secondary for Makad

Patent

Definition: Novel invention — mechanism or method with industrial use.

  • Candidate: 3-axis head (yaw+pitch+roll) in 60 mm neck
  • Candidate: expression composer (face+head+sound sync)
  • Blocker: prior art — Cozmo, research platforms, Plos One nod data
  • My call: document in specs; don't file for student V1

Trade Secret

Definition: Confidential know-how — MJ5 motion params, behaviour timing.

  • Could protect: motion profile numbers, composer timing tables
  • Blocker: public GitHub repo publishes architecture + storyboard
  • India: no standalone statute — NDAs + access control only
  • My call: keep tuning private until demo; can't claim secrecy on published docs

Trademark

Definition: Brand name/logo — "Makad", "M4K4-D", "M4".

  • Class 9 (apparatus) + Class 42 (software) if productized
  • Risk: must not use Disney/Lucasfilm marks (R2-D2, BB-8)
  • Makad name is original — no confusion with existing marks
  • My call: register only if moving beyond academic prototype

Criterion ② · Case Study · Landmark dispute
Landmark Case

Thaler v. Perlmutter (2023) — can AI be an author?

Case facts

  • Dr. Stephen Thaler claimed AI system "DABUS" authored an image — sought US copyright registration
  • US Copyright Office refused — copyright requires human authorship
  • D.D.C. affirmed March 2023: "human creativity is the sine qua non at the core of copyright"
  • WIPO and USCO (2023 guidance) align: AI-assisted OK; AI-alone not an author

Relevance to Makad

  • Makad uses cloud NLU (AI) but all protectable assets are human-authored
  • Face animations, astromech sounds, head motions — designed by me, not generated by model
  • AI is a tool in the pipeline (speech recognition, tracking) — not the author of expressive works
  • If I used AI to generate animations, I'd need to document human creative input for copyright validity

Takeaway: Makad's IP strategy depends on tracing authorship to human design decisions — which my docs and git history support.

Criterion ② · Case Study · Industry Product
Industry Product

Anki Vector (2018) — when an AI robot company shuts down

Case facts & lessons for Makad

  • Anki sold Vector — cloud NLU, expressive LCD face, personality behaviours (~$250 consumer robot)
  • Company bankrupt April 2019 — cloud servers offline; robots lost voice/personality features
  • IP assets (patents, trademarks, codebase) sold to Digital Dream Labs — revival depended on new owner
  • Community Wire-Pod replaced cloud only after DDL open-sourced server code years later
  • Makad parallel: same cloud NLU dependency, same "character layer" as core value
  • My response: open architecture on GitHub; own expression layer (sounds + motions); API ToS audit

Source: TechCrunch Apr 2019 · DDL acquisition filings · Wire-Pod docs

Criterion ④ · Critical Analysis & Innovation Insight
Critical Analysis

Gaps, risks & ethical implications

IP gaps I identified

  • No copyright registration filed — automatic protection exists but registration strengthens enforcement
  • Incomplete license audit — LVGL, OpenCV, ESP-IDF, Pi OS need tracked compatibility matrix
  • Cloud AI ToS unclear — commercial/demo use of API outputs depends on provider terms
  • Public GitHub — transparency for academic eval; destroys trade secret on published assets
  • Derivative-work line — astromech genre OK; must never cross into Disney protected likeness

Ethical & policy implications

  • DPDP Act 2023 (India) — camera + mic person tracking requires consent framework
  • IT Rules 2021 — home robot with recording capability triggers privacy obligations
  • EU AI Act 2024 — transparency on AI subsystems if product ever sold in EU
  • Open vs closed — publishing storyboard helps evaluation but reduces trade secret value

My evaluation: Makad's defensible IP is the authored expression layer — not AI models. Copyright is the only IP type clearly worth acting on before V1.

Criterion ⑧ · Response to Questions (Q&A)
Q&A Preparation

Anticipated questions & prepared answers

  • "Which IP type matters most for Makad?"
    Copyright — all expressive assets are human-authored. Patent/trademark don't fit a student prototype yet.
  • "Can AI own Makad's animations?"
    No — Thaler v. Perlmutter (2023). AI assists NLU/tracking; I authored face, sound, and motion layers.
  • "Is Makad copying Star Wars?"
    Genre inspiration ≠ derivative work. Original name, sounds, silhouette. Must not use Disney marks or R2 likeness.
  • "Why cite Anki Vector?"
    Same product category — AI companion robot, cloud dependency, IP determined survival after shutdown.
  • "Why not patent the 3-axis head?"
    Prior art in desktop robots + Plos One nod research. Filing cost and novelty bar don't fit Dec 2026 student V1.
  • "Who owns cloud NLU output?"
    API provider's ToS governs model output. I own integration code and character layer on top.
  • "Biggest IP risk right now?"
    Incomplete OSS license audit + potential Disney derivative-work line if aesthetic crosses into protected likeness.
  • "What would you file first?"
    Copyright registration on astromech audio + face animations — cheapest, clearest fit for Makad today.
