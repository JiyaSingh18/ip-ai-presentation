Criterion ① · Copyright applied to Makad
Copyright

Copyright — Makad's main protectable asset

Definition

Copyright protects the expression of ideas — not the ideas themselves. Arises automatically when an original work is created and fixed (written, recorded, coded).

Copyrightable works in Makad

  • Astromech audio library — sound recordings (§13)
  • Face animation system — artistic work + software
  • Head motion storyboard HM-00→HM-18 — literary/artistic work
  • Expression composer code — computer program (§2(o))
  • Concept renders, specsheets, vision doc — literary/artistic works

Criterion ① · Patent · Trade Secret · Trademark applied to Makad
Patent · Trade Secret · Trademark

Three IP types — defined & evaluated for Makad

Patent

Definition: Legal monopoly on a new invention — must pass novelty, inventive step, industrial applicability tests (USPTO / IPO India).

  • Candidate: 3-axis head in 60 mm neck envelope
  • Candidate: expression composer coordinating 4 channels
  • Prior art: desktop robots, Plos One nod data, Cozmo-class platforms
  • My evaluation: document in specs; provisional filing only if RP-01 gate proves novelty

Trade Secret

Definition: Information kept confidential that gives business advantage — lost once publicly disclosed (no registration; NDAs enforce).

  • Could protect: MJ5/MS7 motion parameters, composer timing tables
  • Conflict: architecture + storyboard already on public GitHub
  • India: no standalone trade secret statute
  • My evaluation: keep tuning private until demo; can't claim secrecy on published docs

Trademark

Definition: Protects brand identifiers — names, logos — so consumers know product origin (IPO India TM registry).

  • Marks: "Makad", "M4K4-D", "M4" wake word
  • Risk: must not adopt Disney/Lucasfilm marks (R2-D2, BB-8)
  • Class 9 (apparatus) + Class 42 (software) if productized
  • My evaluation: not filing now — no commercial market yet

Research Paper

Research papers as IP — prior art & design input

Definition

A research paper publishes findings into the public domain. It creates prior art (limits patent claims) and can be cited in original work without transferring ownership.

In Makad

  • Plos One 2024 — human nod/shake kinematics → informs RP-01 head motion timing and amplitude decay
  • HRI / puppetry refs — WALL-E, BB-8 animation research → anticipatory motion principles in specs
  • My RP-01 storyboard v0.2 — original 19-motion choreography; cites papers, adds authored keyframes + MJ5 profiles

Distinction: I cite the paper; I copyright my storyboard. The paper's authors hold their IP; prior art blocks identical patent claims.

Criterion ② · Case Study · Landmark dispute
Landmark Case

Thaler v. Perlmutter (2023) — can AI be an author?

Case facts

  • Dr. Stephen Thaler applied for US copyright on image created by AI system "DABUS" with no human creative input
  • US Copyright Office refused registration — human authorship required
  • D.D.C. affirmed March 2023: "human creativity is the sine qua non at the core of copyright"
  • WIPO IP & AI Toolkit (2024) and USCO guidance (2023) align: AI-assisted OK; AI-alone not author

Relevance to Makad

  • Makad uses cloud STT/NLU (AI) but all protectable creative assets are human-authored by me
  • Face animations, astromech sounds, 19 head motions — designed in storyboard, not generated by model
  • AI handles speech recognition and person tracking — pipeline tools, not authors of expressive works
  • Git history + docs prove authorship chain: vision → storyboard → specs → code

Takeaway for Makad: Copyright strategy requires documenting human creative decisions — which my 31K+ doc repo supports.

Criterion ② · Case Study · Industry example
Industry Case Study

Anki Vector shutdown (2019) — IP lifecycle of an AI robot

What happened

  • Anki (2013–2019): Vector — cloud-connected AI companion, expressive face, SDK
  • April 2019 bankruptcy → cloud servers offline → robots lost NLU and personality features
  • IP assets sold to Digital Dream Labs — patents, trademarks, proprietary codebase transferred
  • Community project Wire-Pod replaced cloud dependency after DDL open-sourced server code (2021–22)

Sources: TechCrunch Apr 30 2019 · DDL press releases · Wire-Pod GitHub

Lessons applied to Makad

  • Character IP = survival asset — animations, behaviour logic, personality outlasted the company
  • Cloud NLU = dependency risk — Makad uses APIs too; must plan for provider failure
  • Patents had acquisition value — Anki's portfolio was bought; but community revival needed open code
  • My strategy: own expression layer (copyright); open architecture on GitHub; audit API ToS; keep astromech vocabulary original

Criterion ④ · Critical Analysis
Critical Analysis

Gaps, risks & ethical/policy implications

IP gaps I identified in Makad

  • No copyright registration filed — automatic protection exists; registration strengthens enforcement (copyright.gov.in)
  • Incomplete OSS license audit — LVGL, OpenCV, ESP-IDF, Pi OS need compatibility matrix
  • Cloud API ToS unverified — demo recording / academic use of STT output depends on provider terms
  • Public GitHub — transparency for evaluation vs. trade secret on published motion data
  • Derivative-work boundary — astromech genre safe; film-accurate R2 likeness or sounds would not be

Ethical & policy implications

  • India DPDP Act 2023 — camera/mic person tracking processes personal data; consent framework required
  • IT Rules 2021 — home robot with recording capability triggers privacy obligations beyond IP
  • EU AI Act 2024 — transparency on AI subsystems if Makad ever sold in EU market
  • AI authorship policy — global shift toward human-authorship proof (USCO, WIPO) favours Makad's doc-heavy approach

My evaluation: Makad's defensible IP is the authored expression layer. Copyright is the only IP type worth acting on before V1.

What's innovative & where Makad IP goes next

Criterion ⑧ · Response to Questions (Q&A)
Q&A Preparation

Anticipated questions & prepared answers

  • Define the six IP types for Makad in one line each.
    Copyright = my creative works. Patent = possible head/composer but prior art blocks filing. Trade secret = motion tuning, limited by public repo. Trademark = "Makad" name, not commercial yet. Research paper = Plos One cited as prior art. Industry product = Anki Vector as comparator.
  • Which IP type matters most?
    Copyright — all expressive assets are human-authored. Patent/trademark are secondary for a student V1.
  • Why Thaler v. Perlmutter?
    Landmark ruling that AI alone cannot hold copyright — directly affects how I claim Makad's creative layers.
  • Why Anki Vector?
    Same product category; shows IP lifecycle when an AI companion company fails.
  • How does IP apply to Makad's AI models?
    I don't own the STT model — provider's ToS applies. I own the composer algorithm and all human-authored output layers.
  • Is Makad a Star Wars copy?
    Genre inspiration ≠ derivative work. Original name, sounds, motions. Must not use Disney marks or R2 likeness.
  • Biggest IP gap?
    No copyright registration yet + incomplete OSS license audit.
  • What would you file first?
    Copyright on astromech audio + face animations at copyright.gov.in — clearest fit, lowest cost.
  • Ethical concern beyond IP?
    Camera/mic person tracking under DPDP Act 2023 — consent required regardless of copyright.
