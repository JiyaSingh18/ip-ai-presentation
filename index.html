The Project

What is Makad?

Before IP — the product this talk is about.

In plain English

Makad (M4K4-D, "M4") is a ~30 cm wheeled companion robot — R2-D2 in spirit, not a smart speaker. It lives on your floor, hears you in normal English, tracks you with a camera, moves its head expressively, makes original droid sounds, and can follow you around a room.

Everything — screen, head, sound, wheels — is timed together so M4 feels like one living character, not separate tech demos bolted together.

Innovation

What's actually new in Makad

The innovation isn't a better AI model — it's how AI output gets turned into character.

Expression composer

One semantic intent ("user said yes") → coordinated face + head + astromech sound + wheel motion at the same time. No channel leads alone.

Asymmetric language

M4 understands human speech (English) but responds in an authored droid language — not English TTS. Original sounds, original grammar.

Research-grounded motion

19 head motions with human nod/shake kinematics (Plos One 2024), minimum-jerk profiles MJ5/MS7 — not sine-wave servos.

3-axis expressive head

Yaw + pitch + roll in a 60 mm neck on a floor droid. Face renders locally on ESP32 — semantic state, not video over a moving neck.

Anticipatory character

Head and eyes move before the body accelerates — feedforward animation, like puppetry research (WALL-E, BB-8 refs).

Safety-separated layers

Seeing a person ≠ permission to drive. Motion safety runs independently even if cloud AI or Pi crashes.

IP Risk

Star Wars inspiration — where's the line?

Makad is inspired by the astromech companion archetype. That's not the same as copying protected work.

What Makad does (safe)

  • Original name: Makad, M4K4-D, M4 — not R2-D2 or BB-8
  • Original astromech sounds — composed for this project, documented in intent.md as "not copied film samples"
  • Original silhouette — wheeled floor droid, own head cartridge, scrappy industrial look
  • Genre trope: "small loyal droid companion" — ideas aren't copyrightable, expression is

What would cross the line

  • Film-accurate R2 sound effects or visual decals
  • Disney/Lucasfilm trademarked names or character likeness
  • Marketing as a "Star Wars robot" product

For V1: Makad is inspired by the archetype — every protectable asset (sound, motion, face) is original authored work.

Case Study

Anki Vector — what happens when the company dies?

Real industry example closest to Makad: AI companion robot, cloud brain, expressive face, personality behaviours.

What happened (2019)

  • Anki sold Vector (~$250) — cloud NLU, LCD face, personality engine
  • Company bankrupt → cloud servers offline → robots lost voice and personality
  • Codebase and IP sold to Digital Dream Labs — revival depended on new owner
  • Community Wire-Pod fixed it only after DDL open-sourced server code years later

What I take from this for Makad

  • The character layer (animations, sounds, behaviour timing) is the valuable IP — not the cloud model
  • Cloud NLU is a dependency risk — I document architecture openly but own my expression layer
  • If Makad ever ships, personality IP must survive independently of any one API provider

Research & Prior Art

Standing on published research — without copying it

Makad's motion design cites academic work. That informs design but doesn't transfer ownership.

Research I build on

  • RP-01 storyboard v0.2 — my original 19-motion choreography; cites research, adds authored keyframes

Critical Analysis

Gaps, ethics & my honest read

IP gaps in Makad today

  • No copyright registration yet — protection is automatic but registration helps if disputed
  • License audit incomplete — LVGL, OpenCV, ESP-IDF, Pi OS need a tracked list
  • Cloud API ToS — demo/recording rights depend on provider terms
  • Public GitHub — good for academic transparency; can't claim trade secret on what's published
  • Patent not planned — 3-axis head has prior art; student V1 doesn't justify filing cost

Beyond IP — ethics & policy

  • Camera + mic in home — India DPDP Act 2023 applies to person tracking; consent needed
  • AI transparency — EU AI Act 2024 would require disclosure if productized in EU
  • Human authorship — all creative layers trace to my design; AI is a pipeline tool, not the author

Bottom line: Makad's innovation is the expression system. Its defensible IP is the authored character layer — sounds, motions, animations, composer code.

My Plan

What I'm doing about IP before V1 demo

Concrete steps — not theoretical. This is my IP plan for Makad.

  1. Keep all creative assets original — astromech sounds, face animations, head motions documented as human-authored in git history
  2. Copyright registration — file astromech audio library + face animation assets + storyboard at copyright.gov.in before public demo
  3. OSS license audit — BOM of every library (LVGL, OpenCV, ESP-IDF) with license type and attribution requirements
  4. API ToS review — confirm cloud STT and Spotify terms allow demo recording and academic presentation
  5. Stay on the safe side of inspiration — no film rips, no Disney marks, no R2 likeness in final build
  6. Document authorship chain — vision → storyboard → specsheets → code; proves human creative input post-Thaler
