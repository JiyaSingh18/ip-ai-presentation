What is Makad?

The robot this entire presentation is about.

In plain English

Makad (M4K4-D, "M4") is a small wheeled companion robot — R2-D2 in spirit. It lives on your floor, hears you in normal English, tracks you with a camera, moves its head on 3 axes, makes original droid sounds, and follows you around a room.

It is not a smart speaker or English chatbot. Screen, head, sound, wheels — all timed together so M4 feels like one living character.

Innovation in Makad

What's new in my project

Makad's innovation isn't a better AI model — it's how AI gets turned into character.

Expression composer

One intent ("user said yes") → face + head + astromech sound + wheels fire together. No channel leads alone.

Asymmetric language

M4 understands English but responds in my authored droid language — not TTS, not English speech.

19 head motions

HM-00→HM-18: wake, search, yes/no, laugh, Indian wobble, curious tilt — research-grounded, not sine-wave servos.

Original astromech audio

A-wake-rise, A-affirm, A-laugh… composed for Makad. Explicitly not copied film samples.

Head-local face rendering

ESP32 + LVGL on the moving head — semantic state messages, not video streamed over a gimbal neck.

Anticipatory motion

Head and eyes move before the body accelerates — puppetry-informed, not purely reactive.

Makad's IP Landscape

Patent, trade secret & trademark — do they fit Makad?

Not every IP type applies equally. Here's my honest read for this project.

Patent — Makad's head & composer

  • Could cover: 3-axis head in 60 mm neck on a floor droid; expression composer method
  • Problem: prior art — desktop robots, Plos One nod data, Cozmo-class platforms already exist
  • My plan: document in RP-01 specs; only consider filing if gate evidence proves novelty

Trade secret — Makad's tuning data

  • Could cover: MJ5/MS7 motion parameters, composer timing tables, tracking thresholds
  • Problem: architecture + storyboard already public on my GitHub repo
  • My plan: keep numeric tuning private until V1 demo; can't claim secrecy on published docs

Trademark — Makad's name

  • Could cover: "Makad", "M4K4-D", "M4" as product identifiers
  • Problem: not a commercial product yet — no market to protect
  • My plan: register Class 9 only if Makad moves beyond academic prototype

Makad vs Industry

What Anki Vector teaches Makad

The closest real product to Makad — same category, same cloud dependency, same "character IP" question.

Vector (2018) — what happened

  • AI companion robot — cloud NLU, expressive LCD face, personality behaviours
  • Anki bankrupt April 2019 → servers offline → robots lost voice and personality
  • Codebase + IP sold to Digital Dream Labs — revival depended on new owner
  • Wire-Pod community fixed it only after DDL open-sourced server code

What I take for Makad

  • Vector's character layer (animations, behaviour, personality) was the valuable IP — not the cloud model
  • Makad has the same cloud NLU dependency — I must plan for provider failure
  • My astromech vocabulary + motion storyboard = Makad's "personality IP" — same role Vector's engine played
  • I keep architecture open on GitHub so Makad survives even if a cloud API changes

Makad & AI Authorship

Why Makad's creative layers must be human-authored

Thaler v. Perlmutter (2023): AI alone cannot hold copyright. Makad's protectable assets are everything I designed.

The case — in one paragraph

Dr. Thaler tried to register US copyright on an AI-generated image with no human input. Court refused — human creativity is required. WIPO (2024) and US Copyright Office (2023) agree: AI-assisted work OK; AI-alone not an author.

Applied to Makad's AI/ML stack

  • Cloud STT model — pre-trained, provider-owned; ToS governs transcript output
  • Person tracking — OpenCV/MediaPipe OSS + my tuning code (copyrightable)
  • Makad does not train models — no dataset licensing issue in V1
  • AI-generated text from NLU — not my copyright; my choreographed droid response to that intent IS

Makad assets that pass the human-authorship test

  • 19 head motion keyframes — authored in storyboard v0.2
  • Face animation primitives — E-neutral, E-laugh, E-gaze… designed by me
  • Astromech sounds — human-composed, documented in intent.md
  • Expression composer code — my system design, traceable in git

Bottom line: Makad uses AI as a pipeline tool. The character IP is human-authored — which is exactly what copyright protects.

Makad IP — My Evaluation

Gaps, risks & ethics in Makad's IP plan

IP gaps in Makad today

  • No copyright registration yet — protection is automatic but registration at copyright.gov.in strengthens proof
  • License audit incomplete — LVGL, OpenCV, ESP-IDF, Pi OS need a tracked compatibility list
  • Cloud API ToS unverified — demo recording rights for STT output depend on provider
  • Star Wars inspiration line — genre OK; film-accurate R2 sounds or likeness would not be
  • Public GitHub — good for academic eval; limits trade secret on published storyboard

Ethics beyond IP

  • Camera + mic in home — Makad's person tracking falls under India DPDP Act 2023; consent needed
  • EU AI Act 2024 — would require AI transparency if Makad ever sold in EU

Future outlook for Makad

  • Copyright-register astromech audio + animations before V1 demo
  • Trademark "Makad" only if productized
  • Companion robot moat = personality IP (Anki lesson), not hardware specs

Questions about Makad's IP

  • "What's innovative in Makad?"
    The expression composer — one intent coordinates face, head, sound, wheels. AI handles speech; I authored the character.
  • "What IP does Makad have?"
    Copyright on animations, sounds, 19 motions, composer code, docs. Patent/trademark secondary for now.

    Inspired by the archetype. Original name, sounds, motions. intent.md says no copied film samples.
  • "Why Anki Vector?"
    Same product as Makad — AI companion robot. Shows why owning your character IP matters.
  • "Who owns Makad's AI output?"
    Cloud provider's ToS governs model output. I own the droid response layer built on top.
  • "Can you patent Makad's head?"
    Prior art exists. Copyright on authored assets is the realistic protection for V1.
  • "Biggest IP risk for Makad?"
    Using third-party sounds instead of original astromech library, or incomplete OSS license audit.
  • "What will you file first?"
    Copyright on astromech audio + face animations — clearest fit for Makad today.
