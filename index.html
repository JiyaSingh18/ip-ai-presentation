Introduction

What is Makad & why does IP matter?

Makad is my design project — an AI-powered floor droid. This presentation analyses which IP types protect each part of it.

The product

Makad (M4K4-D) is a ~30 cm wheeled companion robot. It uses AI/ML for natural-language understanding, person tracking, and coordinated expression across face, 3-axis head, astromech audio, and wheels.

Priority: "M4 should feel alive." The innovation is multimodal character coordination — not any single AI model.

Why IP analysis now?

  • Makad combines original creative work (animations, sounds, motions) with AI services (cloud NLU, vision)
  • Before building V1, I need to know: what I own, what I can publish, and what risks exist
  • Companion robot industry (Anki Vector, Jibo) shows IP determines survival after funding ends

Patent · Makad

Patent — mechanical & system inventions

Potentially patentable in Makad

  • 3-axis expressive head mechanism — yaw (base) + pitch (yoke) + roll (face cartridge) in ~250 g, 60 mm neck envelope
  • Expression composer architecture — single semantic intent → coordinated face + head + sound + base with shared timing/interruption rules
  • Independent motion safety layer — safety overrides behaviour even when cloud/NLU fails (AD-04)

Patentability test (India §2(1)(j)): Must be novel, involve inventive step, and be industrially applicable. Prior art: desktop robots with 2-DOF necks — Makad's 3-axis in this size class may qualify if claims are specific enough.

Trade Secret & Trademark

Protecting Makad's know-how & brand

Trade secrets to protect

  • MJ5/MS7 motion profile library — jerk-limited parameters for 19 head motions (storyboard v0.2)
  • Behaviour timing tables — onset/settle delays between face, head, sound channels
  • Person tracking tuning — acquisition thresholds, reacquire logic for 0.3–2 m envelope
  • RP gate evidence data — prototype measurements before public release

India: no standalone trade secret statute — protect via NDAs and access control until patent/copyright filing.

Trademark — brand identity

  • "M4K4-D" — technical designation (Class 9: apparatus; Class 42: software services)
  • "Makad" — consumer-facing droid name
  • "M4" — wake word + shorthand brand

Risk: Star Wars droid aesthetic inspiration — must not copy Lucasfilm/Disney protected marks, character names, or distinctive visual elements. Makad's design is original; R2-D2 likeness is inspiration only.

Case Study · Industry

Anki Vector — what happened when the company died?

Real-world example of IP determining whether an AI companion robot survives.

Case facts

  • Anki (2013–2019) made Vector — AI companion robot with cloud NLU, face, personality
  • Company shut down April 2019 — servers went offline, robots became "bricked"
  • Assets sold to Digital Dream Labs (DDL) — patents, trademarks, codebase acquired
  • Community open-source effort (Wire-Pod) replaced cloud dependency — but only because DDL eventually open-sourced server code

Lessons for Makad

  • Cloud NLU dependency — Makad uses cloud APIs (like Vector) — IP/service continuity risk if provider changes terms
  • Patents had value — Anki's IP portfolio was acquired, enabling robot revival
  • Trade secrets in behaviour — Vector's personality engine was proprietary; lost when company failed
  • My response: Document architecture openly (GitHub) but keep motion/behaviour tuning as trade secrets until V1 demo

Relevance: Makad's expression composer + astromech vocabulary = the "personality IP" that makes it more than hardware.

Critical Analysis

Gaps, risks & my evaluation

IP gaps identified in Makad

  • No filing yet — all protection is automatic copyright only; no patent/trademark registration
  • GitHub is public — publishing code/docs may destroy trade secret status for disclosed items
  • Component licenses — Waveshare, Pi, LVGL, OSS libraries impose license obligations I must track
  • Cloud AI ToS — using OpenAI/Whisper APIs means outputs may have restricted commercial use
  • Aesthetic inspiration — Star Wars droid genre is not owned, but crossing into derivative works is a risk

Ethical & policy implications

  • Camera + mic in home — privacy law (IT Rules 2021) applies; IP doesn't address consent/ recording
  • Person tracking — facial data processing may fall under DPDP Act 2023 (India)
  • Open vs closed — publishing storyboard helps academic evaluation but reduces trade secret value

My conclusion: Makad's defensible IP is the expression layer (animations, sounds, motion choreography) — not the AI models. Patent the head mechanism if RP-01 gate evidence is strong.

Innovation Insight

Recommended IP strategy for Makad V1

  1. Register copyright — file for astromech audio library, face animation assets, and storyboard before public demo (Copyright Office India / USCO if applicable)
  2. Trademark "M4K4-D" / "Makad" — apply in Class 9 (robotic apparatus) before anyone else in companion robot space
  3. Evaluate provisional patent — after RP-01 gate pass, file on 3-axis head mechanism if measurement data supports novelty claims
  4. Keep behaviour tuning private — motion profile numbers and composer timing as trade secrets until Dec 2026 demo
  5. License audit — maintain BOM of all OSS components (LVGL, OpenCV, Pi firmware) with license compatibility matrix
  6. Document human authorship — all creative works must trace to my design decisions (not AI-generated) for copyright validity

Q&A Preparation

Anticipated questions

  • "Can you patent an AI robot?" → Patent the mechanism/system, not the AI model. Makad's head design and composer are patent candidates.
  • "Is Makad a Star Wars copy?" → Genre inspiration ≠ derivative work. Design, name, and sounds are original.
  • "Who owns cloud NLU output?" → API provider's ToS — Makad owns the integration and character layer on top.
  • "Why not open-source everything?" → Docs and architecture yes; motion tuning and behaviour timing are competitive advantage.
  • "Biggest IP risk?" → Publishing prototype evidence on GitHub before patent filing destroys novelty.
  • "What would you file first?" → Trademark on "Makad" + copyright on astromech audio — cheapest and fastest.
